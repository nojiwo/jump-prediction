# v0.14 UI／API結合確認・予想比較表修正（2026-10-13）

## 修正

1. `src/core/prediction-display.ts` を追加。受付中の号があればそれを表示し、なければ直近の受付終了号を予想タブに表示する。準備中の号は一般画面に出さない。
2. `src/App.tsx`: 受付が終了した号について、自分の正式予想（あれば）と締切後の全員の予想比較表を表示できるよう、`/api/prediction` と `/api/prediction-comparison` の呼び出し対象を一致させた。締切後の正式提出・編集は不可。予想未提出の場合は受付終了の案内と比較表のみを表示。新しい号の受付開始後は新しい号の予想画面に切り替える。
3. `src/styles.css` と `src/App.tsx`: 予想比較表を横スクロールする際に左端の順位列を固定。
4. `src/styles.css` と `src/Extras.tsx`: 大会成績表を横スクロールする際に順位列・ユーザー名列を固定。ライト・ダークモードの共通色変数を使用。
5. `tests/prediction-display.test.ts`（4件）と `tests/prediction-comparison-closed.test.mjs`（2件）を追加。締切後のサーバーによる自動終了、本人の正式予想取得、比較表取得、未認証アクセス拒否をSQLite実DBで確認。
