# v0.16 検証記録（2026-10-13）

## 今回変更した機能

1. **受付開始時に未保存の画面設定が反映されない問題を修正。** 管理者画面の「受付を開始」は、表示中の巻頭・センターカラー、予定休載、確認済み状態をまず `/api/admin/issue-setup` に保存し、保存成功後に `open` を呼び出します。保存エラー、矛盾する設定、確認不足の場合は開始処理を呼びません。サーバー側は従来どおり受付開始直前に再検証し、対象作品を固定します。
2. **作品種別（連載／読み切り）変更時の入力欠落を修正。** 選択内容を変更する際に最低1つの掲載号／連載期間が自動補完され、既存の連載履歴は可能な限り維持します。
3. 送信順を検証する純粋関数テスト8件、および実SQLite/APIと接続した受付開始テスト1件を追加しました。
