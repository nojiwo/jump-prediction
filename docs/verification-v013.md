# v0.13 大会失格・集計時点の検証記録（2026-10-13）

## 実装した修正

1. `server/tournaments.js`：大会の指定号が未提出の場合、その直後の実際に登録されたジャンプ号の発売時刻を迎えた時点で失格とする。選択中の最終対象号も正しく判定する。次号が未登録なら失格にしない。判定時刻を引数化して境界テストを固定可能にした。
2. 同：以前の集計時点を選択した際、後の対象号に起因する失格を持ち込まない。一般利用者はその時点までに公開済みの集計号のみ選択可能。
3. 同：失格者の得点は、失格となった未提出号より**前**のものだけを累計に採用する。失格後の号の得点は、個別の号で正式提出・採点済みでも大会成績では計上しない。
4. `src/Extras.tsx`：一般利用者の集計時点セレクターに公開済みの対象号だけを表示。未提出は「未提出」、失格後は「—」、失格前の得点と累計は保持。
5. `src/core/pdf.ts`：大会順位表PDFにも同じルールを反映。
6. `tests/tournament-dq-snapshot.test.mjs`：発売時刻の前後、次号の登録遅延、過去の集計時点、未公開成績の保護、代理提出の実APIと再採点、失格後の得点無効化をDBで検証。`tests/pdf-layout.test.ts`に帳票のマーカー検証を追加。
