## v0.13 大会失格・集計時点の整合性（2026-10-13）

- 「締切後の未提出者」は、その対象号の**直後の登録済みジャンプ号の発売時刻**になって初めて失格となる。大会の最後の対象号の未提出も正しく判定し、次号が未登録なら保留する。
- 「集計時点」を以前の号に戻した場合、選択号より後の対象号の未提出は判定しない。一般利用者は公開済みの集計対象号のみ選択可能。
- 失格前の得点は保持し、未提出の号は「未提出」、以後の大会成績は「—」とし、失格後の得点を累計に加えない。
- 管理者の正式予想代理提出によって、該当の失格状態と関連順位を実際のDBから再計算。大会順位表PDFも表示を一致させる。
- テスト：共通26件、サーバー40件、SQLiteスキーマ検証成功。React画面TSX構文解析成功。**React本番ビルドと実接続は依然未実施。**
