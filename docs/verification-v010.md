# v0.10 検証報告 — 2026-10-13

## この更新で修正した点

1. **管理者管理のUX**（`src/Extras.tsx`）
   - 以前の「ユーザーIDを直接入力」は廃止し、`GET /api/admin/users?q=...` を使ってユーザー名検索から選択する。
   - 現在の権限・選択したユーザー名・変更後の権限を確認できる。検索キーワードが変わったら古い選択を破棄し、誤ったアカウントを変更しない。
   - 変更後は管理者リストと検索結果を再取得し、パスワード入力をクリアする。
   - `owner` 限定の既存サーバー認可と、創設者降格禁止の既存DB制約を維持。
2. **役割変更パスワード再確認の試行回数制限**（`api/admin/roles.js`）
   - スーパー管理者のログイン状態を盗まれても、パスワードを無制限に試せないよう、15分あたり5回までの制限を追加。
   - 再認証成功・DBの権限変更成功後は回数カウントをリセット。
   - サーバー側で引き続き権限・対象ID・確認操作を判定。
3. **API統合テスト**（`tests/role-management.test.mjs`）
   - 管理者検索に秘密情報が含まれないこと、通常管理者からの権限変更拒否、誤パスワード拒否、正しい再認証、創設者の降格禁止、連続失敗時の429制限を検証。

## 実際の確認結果

- `npm test` 成功：**コアテスト20件／サーバーテスト31件＝合計51件**、Pythonスキーマ検証とTypeScriptコア型チェック成功。
- React `App.tsx`、`Extras.tsx`、`main.tsx`、Vite設定の**構文解析0エラー**。構文解析はTypeScript/React全体の型チェックに代わるものではない。
- **`npm run build` は未検証**：この実行環境からnpmレジストリへアクセスできず、React/Vite/@libsql/clientの依存を導入できない。`npm install --offline` もキャッシュ不足で失敗。ビルド成功は主張できない。
- Turso・Vercel・Cloudflareへの実接続、同時アクセス、iPhone実機、PDF印刷は未検証。

## 残る公開条件
