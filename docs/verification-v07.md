# v0.7 変更内容と検証状況

更新日: 2026-10-13

## 本版で新たに実装

- 本戦進出者候補の管理者専用API `GET /api/tournaments?finalCandidates=<本戦stageId>`。前回大会本戦参加者（前回本戦順位順）／今大会予選参加者（予選順位順）／それ以外の登録ユーザーの3グループで表示。同じ人が複数グループにいる場合は同一IDで選択状態を共有。
- `migrations/003_final_selection.sql` を追加。`tournament_stages.finalists_saved_at` を記録し、本戦進出者を「選択内容を保存」しない限り管理者でも発表できないようサーバー側で制御。未公開時に代理追加／除外で変更すると保存状態が失効する。
- 発表前の一般利用者APIから未公開の本戦ステージのID、対象号、参加者を除外。未公開の本戦順位取得は引き続き拒否する。
- 管理者UIで候補をグループ表示し、検索・共有チェック・保存済み状態・発表確認リストを表示。発表後の参加者修正も可能。
- お知らせ本文の見出し／太字／箇条書き／外部リンク装飾、入力補助・公開前プレビュー・非公開・削除を追加。HTMLを直接挿入せず、リンクの http/https 以外はアクティブ化しない。
