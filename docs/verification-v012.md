# v0.12 実装・検証記録（2026-10-13）

## 更新内容

- `src/Extras.tsx`：管理者向け大会管理を「大会設定／予選管理／本戦管理／大会成績」の4つの内部タブに分離。予選・本戦を持たない大会では対応するタブを表示しない。
- `src/Extras.tsx`：予選管理で参加者一覧・人数、ユーザー検索による代理登録、個別の除外操作を追加。代理登録・除外の両方で対象ユーザーを明示した確認ダイアログを表示する。
- `api/tournaments.js`：予選参加者の除外（`action: 'remove'`）を行う場合、`confirmed: true` を必須に変更。認可がない利用者は従来どおり管理者操作不可。
- `src/Extras.tsx`／`src/App.tsx`：一般利用者の大会ページで自身が予選に参加済みなら再登録ボタンを出さない。参加時は「自分で取消できない」旨の確認を表示。
- `src/Extras.tsx`：大会区分を削除した後の再読込で、選択中の区分が存在しなければ有効な区分に切り替える。
- `tests/tournament-participant-management.test.mjs`：除外時の明示確認、確認不足でDBが変更されないこと、通常ユーザーの代理操作禁止、他参加者データの保持を検証。

## 実行結果

- `npm test`：共通25件 + サーバー33件 = **58件成功、0件失敗**。SQLiteスキーマチェックも成功。
- グローバルのTypeScriptによる `src/Extras.tsx`、`src/App.tsx`、`src/StageIssueEditor.tsx` の **TSX構文解析成功**。
- `npm install --fetch-retries=0 --fetch-timeout=5000`：`registry.npmjs.org` の名前解決エラー `EAI_AGAIN` で失敗。**React/Viteの本番ビルド、Reactの型チェック、ブラウザでの実際の動作は未検証**。
