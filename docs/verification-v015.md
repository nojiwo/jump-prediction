# v0.15 検証記録（2026-10-13）

## 変更

1. 予定休載に設定した作品が作品候補リストから消え、管理画面で休載を解除しにくい問題を修正。候補一覧には休載予定作品も表示し、受付開始時に固定する予想対象からのみ除外する。
2. 休載予定作品を同時に巻頭／センターカラーへ指定する矛盾を拒否。カラー・休載指定の重複も拒否する。
3. 実際のサービスへ公開する前にGitHub Actions上で `npm test` と `npm run build` を検証できるワークフロー `.github/workflows/verify.yml` を追加した。ChatGPTとのGitHub接続は不要。

## 実行結果

- `npm test`: 成功（共通処理30件 + サーバー処理45件、合計75件）。データベース構造の検証も成功。
- 追加したサーバー統合テスト3件: 予定休載の編集・解除、受付時の対象除外、カラーとの矛盾拒否。
- `npm install --offline`: npmのローカルキャッシュに必要な依存がなく失敗（ENOTCACHED）。
- `npm install`: npmレジストリのDNS解決失敗（EAI_AGAIN）。
- `npm run build`: React / Viteの依存が導入できないため、まだ実行に成功していない。GitHub Actionsのワークフローは用意したが**実行していない**。

## 残っている重要事項

- 実際の依存パッケージを導入して、TypeScriptの型検査とVite本番ビルドを成功させる。
- VercelのAPIとTursoをテスト環境へ接続し、実際の登録・ログイン・採点・公開を通して検証する。
- APIの認可、受付競合、バックエンド・画面の残る仕様漏れとPDFの日本語・iPhone対応を総点検する。
- GitHubのワークフローが初回に成功した後、`package-lock.json` を生成してコミットし、ワークフローを `npm ci` に切り替える。

**注意:** v0.15はコード更新版であり、正式公開可能な完成品ではありません。ソースコードのZIPをGitHubへ置くことは、公開サービスの運用開始を意味しません。
