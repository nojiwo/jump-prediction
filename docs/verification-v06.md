# v0.6 実装・検証メモ

更新日: 2026-10-13

## 追加した機能

1. **号別順位表**：従来は3×10行＝最大30人で表示が切れていた。現在は30人ずつ複数ページへ自動分割。
2. **作品別採点表**：選択ユーザー列（6、8、10列）ごとにページを分割。24作品行を超えたときも別ページ化。各ページに全作品合計を表示。
3. **大会順位表**：6対象号列×22参加者行単位で複数ページ化。失格表記は保持。
4. **範囲指定**：号別・作品別PDFで全員／予選参加者／本戦進出者／本戦非進出者を指定し、絞った範囲内で順位を算出。
5. **大会の集計時点**：選択した対象号までの累計を指定可能。
6. **印刷セキュリティ**：タイトル、ユーザー名、作品名をHTMLエスケープ。印刷には外部のPDF変換サービスを使わない。

## 自動テスト

- `npm test`：ドメイン・データベース・APIテストを実行する。
- 追加テスト：`tests/pdf-layout.test.ts`（5件）、`tests/pdf-api.test.mjs`（2件）。
- JS/TSX構文解析：TypeScriptの`transpileModule`で確認（ビルド検証の代替ではない）。

## 必要な検証

- 実行環境で `npm install && npm run build` を成功させ、Reactの型とページ描画を検証する。
- iPhone SafariとAndroid Chromeで、PDFプレビューの表示・用紙サイズ・改ページ・日本語フォント・保存操作を検証する。
- Vercel/Turso接続下で実際に権限・範囲を検証する。
- 残りのアプリ機能、公開境界、バックエンドAPIと管理画面の整合性を完成・総合検証する。
