# v0.11 実装・検証メモ（2026-10-13）

## 今回実装した画面

大会管理の「対象号」の内部コード直接入力を廃止し、利用者に分かる形式の選択UIへ変更。

- 大会の新規登録と編集の両方で、予選・本戦の対象号を年度・号番号から追加
- 通常号（1〜55号）と合併号（1・2〜54・55合併号）を一覧から個別選択
- 未登録の将来号も選択可能（既存ジャンプ号マスターに依存しない）
- 開始・終了号を指定して通常号を範囲で一括追加。複数年にまたがる範囲にも対応（最大220号）
- 選択済み対象号をチップ一覧で表示、個別に削除可能
- 同一号の再追加は重複を作らず、通常号と合併号の数字重複や予選・本戦間の重複はエラーで停止
- 編集中はDBへ保存せず、「大会設定を保存」を押したときだけ API に送信
- サーバー側には従来の対象号重複禁止チェックを維持

`src/StageIssueEditor.tsx`, `src/core/stage-issues.ts`, `src/Extras.tsx`, `src/styles.css` を更新。
