# 統合コード v0.5 検証記録（2026-10-13）

このコードは実際の公開を目指した開発中の統合ソースです。**正式運用可能と認証したものではありません。**

## 今回追加／修正

- `PATCH /api/issues`: ジャンプ号の発売日と締切日時の編集。管理者のみ操作可能。日時はタイムゾーン必須、UTCで保存。
- 受付中の締切変更は延長のみで、**元の締切週の日曜23:59:59（日本時間）**を越えられない。締切後・受付終了後は変更不可。凍結した作品スナップショットは維持。
- 準備中の号の日時変更時には `plan_reviewed_at` をリセットし、管理者に再確認を求める。既に公開された採点結果を自動的に非公開に戻さない。
- ジャンプ管理の日時編集ポップアップとデータベース更新経路を追加。
- 大会区分・対象号を編集できる管理API：保存時に既存の予選／本戦参加者を保持。大会区分の削除には明示的な確認を要求。
- 保管した大会を復元する場合、他の開催中大会と対象号が重複するなら復元を拒否する。
- 管理画面に大会設定の編集・保管・復元を追加。
- 本番の「大会」タブを、サンプルの空画面から実際の大会APIに接続するコンポーネントに変更。
- 予想比較画面で本人の列を先頭に表示し、他の列は初回提出順を維持する。巻頭／センターカラーの文字色表示を反映。
- 閉じた号の日時編集では締切日時を送信しないUI不具合を修正。
