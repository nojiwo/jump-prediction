## v0.3 の本番API

- `GET /api/admin/scoring?issue=YYYYNNMM`：管理者のみ、採点対象の固定作品・下書き・実順位・突発休載・未公開得点を返す。
- `POST /api/admin/scoring`：管理者のみ。`{issue,action:"draft"|"preview"|"confirm",order:["0001",...],suddenHiatus:[]}`。**preview はDBを変更しない**。confirm は得点・実順位を一括保存。
- `GET /api/rankings[?issue=YYYYNNMM]`：一般ログインユーザー、**公開済み結果のみ**。
- `GET /api/prediction-comparison?issue=...`：締切後の正式提出のみ。採点結果は一切返さない。
- `GET/POST /api/admin/proxy-prediction`：管理者の代理修正。予想の正式提出と採点再計算を原子的に処理。
- `GET /api/cron/publish`：`CRON_SHARED_SECRET` によるBearer認証が必須。公開時刻を過ぎた号の公開処理。

この版のReact画面では管理者の採点入力と一般ランキングにAPI接続しましたが、React全体の依存導入・ビルド・実機検証はまだです。

本番コードの準備手順・公開前チェックは `docs/implementation-status.md` および `docs/next-steps.md` を参照してください。
